# 드리블·수비 상황 훈련 확장 설계

## 목적

기존의 공간 터치형 패스 문제를 패스·드리블·오프더볼 이동 판단 훈련으로 확장한다. 같은 공격 장면에서도 수비의 위치와 압박 방향에 따라 다른 행동을 선택하게 하고, 코치 검수 단계에서 애니메이션과 설명이 정확히 대응하도록 한다.

## 학습 흐름

1. 수비수가 2초간 움직인 뒤 판단 시점에서 장면을 정지한다.
2. 사용자는 `패스`, `드리블`, `이동` 중 행동을 먼저 선택한다.
3. 패스는 동료, 드리블과 이동은 도착 공간을 터치한다. 드리블은 시작점에서 도착점까지의 경로도 판정한다.
4. 서버는 행동 유형, 대상 또는 도착 영역, 허용 경로, 수비 위험 영역을 함께 평가한다.
5. 결과는 자동 재생한 뒤 `상황 → 판단 → 결과` 단계로 다시 탐색할 수 있다.

## 수비 상황

수비 유형은 전방 압박, 중앙 차단, 측면 유도, 1대1, 수적 우위, 수적 열세로 구분한다. 문제에는 수비수의 시작 위치, 이동 타임라인, 압박 방향, 시야 또는 차단 영역을 저장한다. 같은 공격 배치라도 수비 유형과 움직임이 다르면 별도 문제로 취급한다.

## 판정 모델

정답은 단일 원형 영역이 아니라 다음 조건의 조합이다.

- `actionType`: `pass | dribble | move`
- `target`: 동료 ID 또는 허용 도착 영역
- `path`: 드리블·이동 시 허용 경로와 위험 영역
- `defenseType`: 수비 상황 분류
- `alternatives`: 조건부로 허용되는 차선 행동과 감점 이유

드리블 경로는 시작점과 도착점을 잇는 선분을 기준으로 위험 영역과의 교차 여부를 판정한다. 첫 오답은 수비의 압박 방향을 강조하고, 두 번째 오답은 권장 행동과 경로를 공개한다.

## 결과 애니메이션

각 장면은 공격수·수비수·공의 구조화된 키프레임 타임라인을 가진다. 자동 재생에서는 선택한 행동의 결과를 끝까지 보여준다. 단계 재생에서는 다음 정보를 강조한다.

- 상황: 압박하는 수비수, 막힌 패스 길, 열린 공간
- 판단: 사용자가 선택한 행동·대상·경로와 권장 선택 비교
- 결과: 공 소유 유지, 수비 돌파, 차단 또는 역습 위험

애니메이션은 임의 생성하지 않고 검수된 키프레임을 결정적으로 재생한다. 동작 감소 설정에서는 이동 애니메이션 대신 시작·종료 위치와 화살표를 표시한다.

## 코치 설명과 검수

각 문제는 네 개의 설명 블록을 가진다.

1. 무엇을 봐야 했는가
2. 왜 이 행동이 유리한가
3. 다른 선택은 왜 위험한가
4. 실전에서 기억할 한 문장

각 설명 블록은 애니메이션 구간, 강조할 선수, 공간 또는 경로와 연결한다. 코치가 설명을 선택하면 해당 구간으로 이동해 강조 상태를 확인할 수 있다. 출처, 검수자, 검수 시각, 설명과 타임라인의 승인 상태가 모두 완료된 문제만 공개한다.

## 데이터와 인터페이스 변경

시나리오에 수비 유형, 허용 행동 목록, 타임라인 JSON, 단계별 설명 JSON을 추가한다. 답안 제출에는 행동 유형과 대상 또는 도착 좌표를 포함한다. 응답에는 정오 판정, 대안 행동, 선택 경로와 권장 경로, 재생할 결과 타임라인을 포함한다. 기존 패스 문제는 `actionType: pass`와 빈 타임라인으로 마이그레이션한다.

## 테스트 및 승인 기준

- 패스·드리블·이동의 행동 유형과 대상 판정을 각각 검증한다.
- 드리블 경로가 위험 영역을 통과하거나 경계를 접하는 경우를 검증한다.
- 여섯 수비 유형이 올바른 설명과 타임라인을 불러오는지 검증한다.
- 자동 재생 후 세 단계 탐색, 재생 반복, 동작 감소 표시를 검증한다.
- 설명 블록과 강조 대상이 어긋난 문제는 검수 완료로 전환할 수 없게 한다.
- 검수되지 않은 문제와 답안 데이터는 공개 API에 노출하지 않는다.

## 범위 제외

실시간 자유 조작, 물리 엔진, AI 자동 전술 생성, 코치 영상 업로드, 골키퍼 판단은 이번 확장에 포함하지 않는다.
