# 풋살 전술 훈련 MVP 설계

## 목적

친구들이 모바일에서 다이아몬드 1-2-1의 픽소·알라·피보 역할을 순환 학습하고, 실제 경기에서 위치 선정과 패스 지원을 개선하는 시나리오형 훈련 서비스다.

## 사용자 흐름

방장이 팀방을 만들고 초대 링크를 공유한다. 팀원은 닉네임으로 입장해 `원칙 설명 → 픽소 → 알라 → 피보 → 전체 움직임 → 실전 미션` 순서로 훈련한다. 문제에서는 SVG 경기장의 이동 영역이나 패스 대상을 터치한다. 첫 오답에는 힌트, 반복 오답에는 정답 움직임과 이유를 제공한다.

## 콘텐츠 원칙

모든 문제는 코치 자료의 출처, 전술 원칙, 적용 조건, 권장·비권장 행동, 해설, 검수 상태를 가진다. 검수 완료된 콘텐츠만 공개한다. 코치 자료가 제공되기 전에는 샘플 장면을 제품 조작 데모로만 표시하고 전술적 정답으로 주장하지 않는다.

## 데이터와 권한

팀방, 참여자, 캠페인, 문제, 시도, 원칙별 숙련도, 실전 회고를 D1에 저장한다. 참여자는 기기 복귀 키로 인증하며 서버에는 키 해시만 둔다. 팀에는 완료율과 취약 원칙만 공유하고 상세 오답은 본인에게만 보인다. 답안 저장 실패 시 기기에 임시 저장하고 재연결 시 동일 이벤트 ID로 중복 없이 동기화한다.

## 성공 기준

친구 4명 이상이 약 10분 안에 캠페인을 완주하고, 실제 경기 전후 체크리스트에서 폭 유지·삼각형 지원·피보 연결·공수 전환이 개선되는지 확인한다.
