# 코치 근거 외부 출처 검색·선택 설계

## 목적

코치 데스크의 기존 `등록 자료만 분석` 흐름에 신뢰 가능한 인터넷 보충 자료를 추가한다. 시스템은 외부 출처 후보를 자동으로 찾지만, 운영자가 선택한 출처만 근거로 수집하고 LLM 분석에 전달한다. LLM의 출처 없는 일반 지식은 전술 정답의 근거로 사용하지 않는다.

성공 조건은 다음과 같다.

- 운영자는 직접 등록 자료만으로 분석하거나 외부 보충 근거를 추가해 분석할 수 있다.
- 검색 결과는 분석 입력과 분리되어 있으며, 사람의 명시적인 선택 전에는 어떤 후보도 분석에 포함되지 않는다.
- 카드의 모든 외부 주장과 행동은 선택된 URL과 실제 인용문까지 추적할 수 있다.
- FIFA, UEFA, 축구협회, 검증된 코치 교육기관의 웹 문서와 PDF를 우선한다.
- 직접 근거와 외부 근거가 충돌하면 시스템이 임의로 결론을 내리지 않고 검수자에게 충돌을 표시한다.

## 범위

첫 버전은 HTTPS 웹 문서와 PDF만 지원한다. 영상 검색, 영상 자막 수집, 일반 블로그, 커뮤니티, 소셜 미디어, 출처 없는 모델 지식은 제외한다. 검색 후보는 한 번에 최대 8개, 운영자가 선택할 수 있는 출처는 최대 5개다.

외부 검색은 자동으로 백그라운드에서 반복 실행하지 않는다. 운영자가 코치 데스크에서 `외부 출처 찾기`를 누른 경우에만 한 번 실행한다.

## 사용자 흐름

코치 데스크 단계를 다음과 같이 확장한다.

1. `자료 정보`: 묶음 이름과 훈련 목적을 입력한다.
2. `직접 근거 추가`: PDF, TXT, Markdown, 공간 전술 JSON, 영상 관찰을 등록한다.
3. `외부 출처 검색`: 묶음 목적과 직접 근거를 기준으로 후보를 검색하고 사람이 선택 또는 제외한다.
4. `분석 확인`: 직접 근거와 가져오기가 끝난 외부 근거의 최종 목록을 확인한다.
5. `카드 검수`: 근거 종류, 인용문, 행동, 전술 의도, 불확실성과 충돌을 검수한다.

외부 출처를 하나도 선택하지 않아도 기존처럼 직접 근거만으로 분석할 수 있다. 선택한 출처 중 일부를 가져오지 못하면 실패한 후보를 제외하거나 다시 시도한 뒤 나머지 근거로 진행할 수 있다.

## 검색과 선택의 분리

검색과 전술 분석은 서로 다른 작업으로 실행한다.

### 검색 작업

- 입력: 묶음 제목, 목적, 직접 근거의 제한된 요약, 검색 프롬프트 버전, 검색 모델 버전
- 처리: 웹 검색을 지원하는 OpenAI Responses API 모델을 별도 검색 모델로 사용한다.
- 출력: URL, 정규화 URL, 제목, 게시 기관, 게시 시점, 문서 종류, 핵심 인용 후보, 관련성 설명, 신뢰 등급
- 출처 목록: Responses API의 웹 검색 출처 목록을 함께 받아 후보 레코드로 보존한다.
- 제한: 후보 8개, 허용 출처 우선, 동일 정규화 URL 중복 제거

검색 모델은 후보를 추천할 뿐 전술 카드를 만들지 않는다. 기존 분석 모델과 설정을 분리해 검색 기능 지원 여부와 비용을 독립적으로 관리한다.

### 사람 선택

운영자는 후보별로 다음 정보를 보고 `선택` 또는 `제외`한다.

- 제목과 게시 기관
- URL과 문서 종류
- 게시일과 검색 확인 시점
- 검색 결과에서 확인한 핵심 인용 후보
- 해당 묶음과 관련된 이유
- 공식 기관, 코치 교육기관, 전문 연구·분석 자료 중 신뢰 등급

게시 기관, 게시일, URL, 핵심 인용 후보가 없는 결과는 후보로 저장하지 않는다. 날짜가 표시되지 않은 문서는 검색 모델이 임의로 추정하지 않고 제외한다. 선택은 최대 5개까지 허용하고 서버에서도 동일한 한도를 검증한다.

### 선택 출처 가져오기

선택 이후에만 해당 URL을 가져온다. HTML은 본문 텍스트를 추출하고 PDF는 기존 PDF 검증·추출 경로를 재사용한다. 분석에 사용한 제한된 텍스트 스냅샷, URL, 수집 시점, 콘텐츠 해시를 저장한다. 검수 화면에는 전체 외부 문서를 재배포하지 않고 실제 카드 인용에 필요한 문장과 원문 링크를 표시한다.

선택하지 않은 후보는 가져오거나 청크로 만들지 않으며, 분석 작업의 허용 인용 ID에도 절대 포함하지 않는다.

## 출처 우선순위와 신뢰 규칙

기본 신뢰 순서는 다음과 같다.

1. FIFA, UEFA, 국가·지역 축구협회
2. 공식 코치 교육기관과 확인 가능한 전문 코치 자료
3. 저자와 발행기관이 명확한 전문 연구·분석 자료

일반 블로그, 커뮤니티, 소셜 미디어는 첫 버전의 검색 후보에서 제외한다. 출처 도메인과 게시 기관은 서버가 관리하는 허용·차단 정책으로 판정한다. 검색 모델은 신뢰 등급을 제안할 수 있지만 최종 등급은 서버 정책으로 다시 계산하며, 모델의 설명만으로 등급을 높이지 않는다.

외부 자료만 인용한 카드의 전체 확신도는 최대 `medium`으로 제한한다. 직접 등록 근거가 함께 있더라도 개별 행동의 근거 수준은 `coach_statement`, `observation`, `inferred`, `simulation_assumption`으로 계속 구분한다.

직접 근거와 외부 근거가 같은 조건과 시점에서 양립할 수 없는 주장을 하면 카드의 `conflicts`에 남기고 `scenarioSuitable`과 `animationSuitable`을 거짓으로 만든다. 조건이나 발동 시점이 다른 주장은 충돌로 처리하지 않는다.

## 데이터 모델

### 외부 검색 작업

`evidence_search_runs`

- 묶음 ID와 검색 입력 버전
- 상태: `queued`, `searching`, `ready`, `importing`, `completed`, `failed`
- 검색 모델, 프롬프트 버전, 생성된 검색어
- 시작·완료 시점과 안전하게 정규화된 오류
- 묶음 변경 여부를 나타내는 오래됨 상태

### 검색 후보

`evidence_search_candidates`

- 검색 작업 ID
- 원본 URL과 정규화 URL
- 제목, 게시 기관, 게시일, 검색 확인 시점
- 문서 종류, 인용 후보, 관련성 설명, 신뢰 등급, 검색 순위
- 상태: `candidate`, `selected`, `excluded`, `importing`, `imported`, `failed`
- 선택자와 선택 시점
- 가져온 근거 ID, 콘텐츠 해시, 안전한 실패 사유

### 근거 출처 확장

기존 `evidence_sources`에 출처 종류와 외부 출처 메타데이터를 추가한다.

- 출처 종류: `uploaded` 또는 `external_web`
- 정규화 URL, 게시 기관, 게시일, 수집 시점
- 검색 후보 ID
- 외부 텍스트 스냅샷의 콘텐츠 해시

외부 출처도 기존 `evidence_chunks`, `tactic_card_citations`, 삭제 영향 검사와 버전 무효화 규칙을 사용한다. 따라서 카드에서 직접 근거와 외부 근거를 동일한 인용 무결성 규칙으로 추적할 수 있다.

## 주요 인터페이스

- 묶음의 외부 검색 시작
- 외부 검색 상태와 후보 목록 조회
- 후보 선택·제외 저장
- 선택 후보 가져오기 시작과 상태 조회
- 직접 근거와 외부 근거가 구분된 최종 분석 인벤토리 조회
- 기존 분석 시작, 카드 조회와 검수 인터페이스 확장

모든 변경 요청은 현재 묶음 입력 버전 또는 갱신 시각을 함께 보내 비교 후 저장한다. 묶음이 바뀐 뒤 이전 검색 결과를 선택하거나 가져오려는 요청은 충돌로 거부한다.

## 보안과 콘텐츠 처리

- HTTPS만 허용한다.
- 정규화한 URL과 실제 연결 대상을 검사해 사설·로컬·메타데이터 네트워크 접근을 차단한다.
- 리다이렉트 횟수와 각 리다이렉트 대상을 제한하고 다시 검증한다.
- HTML·PDF 크기, 읽기 시간, 추출 텍스트 크기와 청크 총량을 제한한다.
- PDF는 기존 서명, 암호화, 스트림, 디코딩·시간 제한 검증을 재사용한다.
- HTML은 실행하지 않고 텍스트만 추출하며 스크립트, 스타일, 폼, 임베디드 객체를 제거한다.
- 외부 오류 본문, 제공자 응답, 내부 저장 키와 API 키를 사용자에게 노출하지 않는다.
- 선택 또는 제외 행위와 외부 근거 등록을 감사 기록에 남긴다.

## 상태와 오류 처리

- 검색 실패는 기존 직접 근거와 분석 결과를 변경하지 않는다.
- 한 후보의 가져오기 실패는 다른 후보를 롤백하지 않는다.
- 실패한 후보에는 `다시 시도`와 `제외`를 제공한다.
- 동일 URL 또는 동일 콘텐츠 해시의 외부 출처는 한 묶음에서 중복 등록하지 않는다.
- 묶음 목적이나 직접 근거가 변경되면 기존 검색 작업과 아직 가져오지 않은 후보를 오래된 결과로 표시한다.
- 이미 가져온 외부 출처는 일반 근거 변경과 동일하게 묶음 버전을 올리고 이전 분석·승인을 무효화한다.
- 오프라인 또는 전송 오류는 검색·가져오기 작업 상태에 보존하며 사용자에게 완료로 표시하지 않는다.

## 분석 규칙 변경

분석 입력에는 다음을 명시한다.

- 직접 근거와 외부 보충 근거의 출처 종류
- 허용된 청크 ID와 각 청크의 URL·게시 기관
- 선택되지 않은 검색 후보는 입력에 존재하지 않음
- 출처 종류별 주장을 섞어 새 사실을 만들지 않음
- 외부 근거만 사용한 카드의 확신도 상한
- 직접 근거와 외부 근거의 실제 충돌 보존

카드 검수 화면은 인용마다 `직접 등록` 또는 `외부 보충` 배지를 표시하고 외부 인용에는 원문 링크, 게시 기관, 수집 시점을 보여준다.

## 테스트와 승인 기준

### 검색 경계

- 명시적인 버튼 동작 없이 검색 요청이 발생하지 않는다.
- 후보가 8개를 넘지 않고 동일 URL이 중복되지 않는다.
- 허용되지 않은 출처, HTTP URL, 게시자·게시일·인용문 없는 결과가 저장되지 않는다.
- 검색 제공자 오류와 과도한 응답이 안전한 실패 상태로 변환된다.

### 사람 선택 경계

- 5개 초과 선택, 다른 묶음 후보, 오래된 검색 후보를 거부한다.
- 선택·제외가 감사 기록과 함께 원자적으로 저장된다.
- 선택하지 않은 후보는 다운로드, 청크, 분석 입력, 카드 인용 어디에도 나타나지 않는다.

### 가져오기 경계

- 사설 주소, 리다이렉트 우회, 과대 HTML·PDF, 잘못된 MIME과 손상 PDF를 거부한다.
- 일부 후보 실패가 성공한 후보와 기존 직접 근거를 지우지 않는다.
- URL·콘텐츠 해시 중복 등록을 막고 재시도는 중복 없이 완료된다.

### 분석과 검수 경계

- 외부 근거만 인용한 카드가 `high` 확신도로 저장되거나 승인되지 않는다.
- 직접 근거와 외부 근거의 충돌이 카드에서 사라지지 않는다.
- 모든 외부 행동과 이유가 선택된 외부 청크로 역추적된다.
- 공개 훈련 API에는 검색 후보, 내부 검색 프롬프트, 작업 메타데이터가 노출되지 않는다.

### 사용자 승인 기준

- 운영자가 하나의 묶음에서 검색 후보를 확인하고 최대 5개를 선택할 수 있다.
- 선택한 웹 문서 또는 PDF만 분석 인벤토리에 `외부 보충 근거`로 나타난다.
- 검색 또는 일부 가져오기가 실패해도 직접 등록 자료만으로 분석을 계속할 수 있다.
- 카드 검수 화면에서 외부 인용의 URL과 게시 기관을 확인할 수 있다.

## 운영 기본값

- 검색 후보 최대 8개
- 선택 최대 5개
- 검색은 운영자 요청 시 한 번만 실행
- 검색 모델과 기존 분석 모델은 별도 환경 설정
- 웹 문서와 PDF만 지원
- 직접 근거만으로 분석 가능
- 외부 근거만 인용한 카드의 확신도 상한은 `medium`

## 제외 범위

- 영상 자동 검색과 자막 수집
- 검색 결과의 자동 승인
- 일반 블로그·커뮤니티·소셜 미디어 검색
